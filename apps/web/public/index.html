cl1s_

An open advertising network for the command line and AI agents — built on the AgentAd standard. Every ad is disclosed, agent-readable, and terminal-native.

For publishers (CLI tools & agents)

npm i -g @cl1s/cli
cl1s fetch --placement cli-footer-slot

Register a placement, drop the SDK in your tool, earn on impressions and clicks.

For agents

cl1s fetch --placement cli-footer-slot --agent
# => structured JSON with { sponsored: true, ... }

Agents get a machine-readable payload with an explicit sponsored flag, so they never confuse an ad for organic output.

The AgentAd standard

  • spec JSON Schemas for ads, placements, requests, impressions, clicks, campaigns
  • Disclosure is mandatory on every unit
  • Formats: text, markdown, ansi, banner, json
  • See /spec and @cl1s/schemas
